# `/merai` – Custom Mercenary AI Guide

`/merai` works exactly like `/hoai` for Homunculus.

## How to use
1. Summon a mercenary.
2. Type `/merai` in chat.
3. Message should say the mercenary AI has been customized.
4. If it says “Basic”, type `/merai` again.

## Recommended AI
- Modern AzzyAI forks that include mercenary support
- Server-provided custom AI packs
- Aggressive AI packs that support both Homunculus and Mercenaries

## Tips for Mid-rate
- Lower AggroHP so the mercenary starts fighting earlier
- Enable skill usage
- Keep an eye on SP – some mercenaries spam skills heavily

Place any custom `AI_M.lua` or USER_AI mercenary files according to the AI pack instructions.
